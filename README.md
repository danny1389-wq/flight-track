# SYD to SGN fare tracker
1. Create a new **public** GitHub repo and upload everything in this folder (keep the `.github` and `data` folders).
2. Settings > Pages > Deploy from branch > `main` / root. Your dashboard appears at the URL shown there.
3. Actions tab > Track fares > Run workflow. It then runs daily by itself.
Edit the date window and trip lengths at the top of `tracker.py`.
